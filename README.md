
# Week 8 Final Project – SQL Database and Queries  

This project is the final assignment for Week 8. It demonstrates SQL fundamentals, database normalization, joins, and aggregations in a real-world **e-commerce** scenario.  

## 🚀 Features  
- MySQL database running in Docker  
- Tables for customers, products, orders, payments, and order details  
- Sample data preloaded for testing  
- Assignment queries in `answers.sql`  
- GitHub Actions CI pipeline to automatically check queries
